# PROJECT_DOCS.md — Технічна документація проєкту "Grafik Gillette"

Цей документ призначений для швидкого ознайомлення з архітектурою та структурою проєкту.

## 1. ЗАГАЛЬНИЙ ОПИС
**Grafik Gillette** — це веб-додаток (PWA) для візуалізації та керування робочим графіком чотирьох бригад (A, B, C, D) на підприємстві Gillette. Додаток дозволяє відстежувати зміни (Ранок, День, Ніч), планувати відпустки, додавати надурочні години (надгодини) та синхронізувати дані через Google Drive.

### Технологічний стек
- **Frontend**: Vanilla HTML5, CSS3 (Custom Properties, Flexbox, Grid), Vanilla JavaScript (ES6+).
- **Backend**: Відсутній (повністю клієнтський додаток).
- **Персистентність**: `localStorage` для локального зберігання + Google Drive API для синхронізації.
- **PWA**: Service Worker (`sw.js`) для роботи в офлайн-режимі.

## 2. СТРУКТУРА ФАЙЛІВ

### Основні файли
- `index.html` — **Головний робочий файл**. Єдина точка входу, що містить структуру UI та стилі.
- `manifest.json` — Конфігурація PWA (назва, кольори, іконки).
- `sw.js` — Service Worker для кешування ресурсів та офлайн-доступу.
- `.agent.md` — Інструкції для AI-асистентів щодо стилю кодування та рев'ю.

### Директорія `js/` (Модульна логіка)
Проєкт було рефакторизовано: старий монолітний JS розділено на логічні модулі:
1. `data.js` — Заводські графіки (`factorySchedule`), назви місяців, константи та ключі `localStorage`.
2. `core.js` — Основна бізнес-логіка: розрахунок свят (Великдень), робота з `localStorage`, обчислення категорій надгодин (50%/100%/200%).
3. `ui.js` — Утиліти для інтерфейсу: модальні вікна, тости (сповіщення), екранування HTML.
4. `edit.js` — Логіка режиму редагування, буфер незаписаних змін (`pendingChanges`), Undo/Redo.
5. `dashboard.js` — Рендеринг головного екрана (статистика, поточна зміна, найближчі дні).
6. `calendar.js` — Генерація сітки календаря для виду "Місяць".
7. `views.js` — Рендеринг альтернативних видів: "Тиждень", "Рік", "Таблиця".
8. `actions.js` — Обробка дій меню: експорт JSON/ICS, імпорт, очищення даних, керування лімітами відпусток.
9. `pwa.js` — Реєстрація Service Worker та логіка оновлення додатку.
10. `sync.js` — Інтеграція з Google Drive API для бекапу в хмару.
11. `main.js` — Точка входу: ініціалізація стану, роутинг (через URL параметри), обробка подій клавіатури та жестів.

### Директорія `tools/`
- `split_html.py` — Скрипт, що був використаний для розділення старого монолітного HTML на поточну модульну структуру.
- `generate_icons.py` — Утиліта для генерації PWA-іконок.

### Застарілі файли (History)
Раніше проєкт складався з одного файлу `Gillette 2026 New UI overtime.html`. Поточний `index.html` є його сучасною, модульною та функціонально повною версією. Всі інші файли з назвою `Gillette 2026...html` в корінні є застарілими чернетками.

## 3. АРХІТЕКТУРА ТА СТАН

### Глобальні змінні стану (`js/main.js`)
- `currentYear`: Поточний вибраний рік (default: 2026).
- `currentMonth`: Поточний місяць (1-12).
- `selectedShift`: Вибрана бригада (A, B, C або D).
- `currentView`: Активний вид (`dashboard`, `month`, `week`, `year`, `table`).
- `editMode`: Boolean, чи активовано режим малювання графіка.

### Зберігання даних (localStorage)
| Ключ | Призначення |
| :--- | :--- |
| `gillette_prefs_v1` | Налаштування: рік, бригада, тема, вид, ліміти відпусток. |
| `gillette_notes_v1` | Текстові нотатки користувача до конкретних дат. |
| `gillette_urlops_v1` | Масиви дат відпусток для кожної бригади. |
| `gillette_custom_schedule_v2` | Об'єкт з ручними змінами в графіку (перезаписує factorySchedule). |
| `gillette_overtimes_v1` | Дані про надгодини (кількість годин, тип). |

## 4. МОДЕЛЬ ДАНИХ

### Графік змін
Зберігається в `factorySchedule` (js/data.js) та `customSchedule` (localStorage).
Формат: `Year -> Month -> Brigade -> Array[days]`.
Значення: `'R'` (Ранок), `'P'` (Пополудень), `'N'` (Ніч), `''` (Вихідний).

### Формат ключів для маппінгу
- **Відпустки/Нотатки**: `YYYY-MM-DD` (напр. `2026-05-01`).
- **Надгодини**: `YYYY-MM-DD-Brigade` (напр. `2026-05-01-A`).
- **Об'єкт надгодин**: `{ przed: { hours: 4 }, po: { hours: 2 } }`.
