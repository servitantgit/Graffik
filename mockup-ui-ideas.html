6. Наскрізні ідеї продукт

  • Розвести «UI-синій» і «N» high
    Заголовки / посилання / focus = нейтраль сірий або amber accent; ніч = окрема палітра (фіолет або slate).
  • Єдина легенда кольорів high
    R/P/N/W/U однаково в місяці, тижні, році, табелі. Зараз дрібні розбіжності в градієнтах.
  • Режим «спокійний календар» med
    Toggle: full fill ↔ color strip only (менше рябіння при довгому перегляді).
  • Табель: sticky first column + denser headers med
    Дата одним рядком 11
    Пн     → 11 Пн дрібніше; більше днів на екрані.
  • Рік: клік по місяцю = місяць, long-press/secondary = табель low
  • Тиждень: вертикальний timeline на mobile med
    Замість 7 вузьких колонок — список днів зліва направо скрол або stack.
  • Контраст W (вільний) med
    Зараз сірий зливається з фоном клітинки; трохи світліший/темніший + іконка 🏖️ опційно.
  • Today low
    Єдиний маркер (золота обводка) у всіх виглядах; не жовта заливка шапки в табелі (плутанина зі «святом»).
  • Доступність med
    Не лише колір: літера R/P/N завжди видима; pattern (смужки) для N опційно.

7. Рекомендований пакет для першої ітерації

Якщо брати мінімум з максимальним ефектом:

  1. Табель: сірі заголовки дат (варіант A), вихідні — риска, не червоний блок.
  2. N: зсунути в фіолет #7c3aed (або slate) глобально — рік/місяць/тиждень/табель.
  3. Дашборд hero: нейтральний градієнт замість синього «corporate».
  4. Тиждень: strip-картки замість full-bleed (опційно).
